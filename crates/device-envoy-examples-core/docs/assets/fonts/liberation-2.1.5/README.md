# Liberation Fonts 2.1.5

These unmodified Liberation Sans and Liberation Mono files come from the
official
[Liberation Fonts 2.1.5 release](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5).
They make SVG rasterization and the DNS tester golden images independent of
fonts installed on the developer or CI machine.

The font files are distributed under the SIL Open Font License 1.1 in
[`LICENSE`](LICENSE).
