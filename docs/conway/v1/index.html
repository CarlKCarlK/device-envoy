Device Envoy: Conway Demo on Virtual LED Panel

The same Rust core runs on ESP32, Pico 1/2, and in your browser via WebAssembly.

Keys: Space play/pause, N next, P predecessor search, Esc cancel, M cycle color, [ slower, ] faster, 0–9 select pattern.
